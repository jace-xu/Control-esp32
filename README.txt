== Version 1.0.1 ==

1. 总览:
    1.1 建议把这个压缩包里的内容，统一放到项目文件夹内的一个子文件夹里（最好全英文无特殊字符）
    1.2 结构：BottomControl <- Motor <- ControlSerial (箭头指向父级)
    1.3 导入了父级后，理论上不需要导入子级（比如只需要导入BottomControl就可以控制底盘），但是为了清晰也可以导入其他（无影响）
    1.4 导入之后，把鼠标悬停在对应的类、函数上时，会显示相应的解释，详情自行查阅
    1.5 虽然提供了更改电机地址的接口，但尽量不要使用
    1.6 运行模式，目前只提供了速度模式的接口，后续会更新其他模式
    1.7 本来还有其他细的参数（比如加速度、同步等等，暂时没用到，所以都是直接使用了默认值，后续有需要可以在更新时加入）
    1.8 编写底盘和机械臂的代码时，建议也封装成类，整合时会更方便（但注意某些全局对象只能在外部创建一次，然后传入）
    1.9 有问题、BUG或新的需求可以找我，不建议直接改，后续整合可能会乱
    1.10 请先按照MotorSettings里的参数设置电机
    1.11 电机地址不能超过16
    1.12 目前并没有考虑多线程，因此非线程安全，建议先不要用多线程，后续会更新多线程部分
    1.13 由于电机接收端频率较低，每次发送完信号会隐式地等待2ms(写在方法里了)，所以使用时注意等待时间的问题

2. 使用方法：
    2.1 创建需要的对象
    2.2 比如要控制整个底盘(小车整体)，就调用 底盘控制对象.motors_control(参数) 就可以控制小车运动
    2.3 如果是要控制某个电机，就调用 电机对象.方法(参数) 单独控制某一个电机
    2.4 不需要直接操作串口，通讯部分已经集成在类里了

3. ControlSerial:
    3.1 这是串口类，用于电机控制串口
    3.2 注意，该类的对象只能创建一次（在整个程序中）且无法复制，建议在最开始创建，后续使用时直接使用该对象或引用，但不要修改
    3.3 创建时需传入波特率、RX引脚、TX引脚

4. Motor:
    4.1 这是电机类，用于创建电机对象并调用电机的方法
    4.2 注意，该类的对象无法复制，后续使用时直接使用该对象或引用，但不要修改
    4.3 创建时需传入ControlSerial对象（全局电机控制串口对象）和该电机的地址

5. BottomControl：
    5.1 这是底盘控制类，集成了四个电机（1 ~ 4地址）并通过速度直接控制整个底盘
    5.2 注意，该类的对象只能创建一次（在整个程序中）且无法复制，建议在最开始创建，后续使用时直接使用该对象或引用，但不要修改
    5.3 创建时需传入ControlSerial对象（全局电机控制串口对象）
