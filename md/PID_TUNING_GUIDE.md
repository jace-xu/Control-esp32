# PID 控制调参指南

## 概述

代码已升级为完整的 PID 控制器。当前默认参数:
- **Kp = 30.0** (比例项,已启用)
- **Ki = 0.0** (积分项,默认关闭)
- **Kd = 0.0** (微分项,默认关闭)

你可以根据实际效果逐步调整参数。

---

## PID 三个项的作用

### P 项(比例项) - 主要控制力

```
输出 = Kp × 当前误差
```

**作用**: 误差越大,输出越大,快速响应

**效果**:
- Kp 太小 → 响应慢,收敛慢
- Kp 太大 → 震荡,超调
- Kp 合适 → 快速接近目标

**当前值**: 30.0

---

### I 项(积分项) - 消除稳态误差

```
输出 = Ki × ∫误差×dt (累积误差)
```

**作用**: 累积历史误差,消除长期偏差

**效果**:
- Ki = 0 → 可能有稳态误差(停在目标附近但不完全对准)
- Ki 太小 → 消除稳态误差慢
- Ki 太大 → 积分饱和,超调,震荡

**什么时候需要 I 项?**
- 如果只用 P 控制,发现误差进入死区后还有偏差
- 如果目标一直在晃动,但电机停在附近不动

**当前值**: 0.0 (关闭)

---

### D 项(微分项) - 抑制震荡

```
输出 = Kd × (当前误差 - 上次误差) / dt (误差变化率)
```

**作用**: 预测趋势,提前刹车,减少超调

**效果**:
- Kd = 0 → 可能震荡
- Kd 太小 → 抑制震荡效果不明显
- Kd 太大 → 对噪声敏感,抖动

**什么时候需要 D 项?**
- 如果 P 控制调高后出现震荡
- 如果电机来回摆动,无法稳定

**当前值**: 0.0 (关闭)

---

## 调参步骤(推荐)

### 第一步: 只用 P 控制(当前状态)

**目标**: 找到合适的 Kp

在 `main.cpp` 的 `setup()` 里添加:
```cpp
void setup() {
    // ... 原有初始化代码 ...
    
    // 只调 P 项
    g_arm_control->setAnglePID(30.0f, 0.0f, 0.0f);
    g_arm_control->setForwardPID(30.0f, 0.0f, 0.0f);
}
```

**测试**:
1. 按住 A 键,观察机械臂响应
2. 如果太慢 → 增大 Kp (比如 40, 50)
3. 如果震荡 → 减小 Kp (比如 20, 15)
4. 找到一个"快速但不震荡"的 Kp

**示例**:
```cpp
// 响应太慢
g_arm_control->setAnglePID(50.0f, 0.0f, 0.0f);  // 提高 Kp

// 震荡严重
g_arm_control->setAnglePID(15.0f, 0.0f, 0.0f);  // 降低 Kp
```

---

### 第二步: 加入 I 项(如果有稳态误差)

**什么是稳态误差?**
- 机械臂停下来了,但没有完全对准目标
- 误差在死区附近徘徊(比如误差 = 3,死区 = 5)

**调整方法**:
```cpp
// 从小开始尝试
g_arm_control->setAnglePID(30.0f, 0.5f, 0.0f);   // 加入小的 Ki
g_arm_control->setForwardPID(30.0f, 0.5f, 0.0f);
```

**测试**:
1. 观察是否能完全对准目标
2. 如果还有偏差 → 增大 Ki (1.0, 2.0)
3. 如果超调或震荡 → 减小 Ki (0.2, 0.1)

**注意**: Ki 通常比 Kp 小很多(1/10 ~ 1/100)

---

### 第三步: 加入 D 项(如果震荡)

**什么时候需要 D 项?**
- 调高 Kp 后出现震荡
- 机械臂来回摆动

**调整方法**:
```cpp
// 从小开始尝试
g_arm_control->setAnglePID(30.0f, 0.5f, 5.0f);   // 加入 Kd
g_arm_control->setForwardPID(30.0f, 0.5f, 5.0f);
```

**测试**:
1. 观察震荡是否减少
2. 如果还震荡 → 增大 Kd (10, 15)
3. 如果抖动 → 减小 Kd (2, 1)

**注意**: Kd 对噪声敏感,不要设太大

---

## 典型参数组合

### 保守型(平滑但慢)
```cpp
g_arm_control->setAnglePID(20.0f, 0.2f, 3.0f);
g_arm_control->setForwardPID(20.0f, 0.2f, 3.0f);
```

### 平衡型(推荐起点)
```cpp
g_arm_control->setAnglePID(30.0f, 0.5f, 5.0f);
g_arm_control->setForwardPID(30.0f, 0.5f, 5.0f);
```

### 激进型(快速但可能震荡)
```cpp
g_arm_control->setAnglePID(50.0f, 1.0f, 10.0f);
g_arm_control->setForwardPID(50.0f, 1.0f, 10.0f);
```

## 高级调整

### 调整积分限幅(防止积分饱和)

如果发现 I 项累积太多,导致超调:
```cpp
g_arm_control->setIntegralLimit(500.0f);  // 默认 1000
```

### 调整死区

如果精度要求高:
```cpp
g_arm_control->setDeadzone(2.0f);  // 默认 5.0,改小提高精度
```

如果抖动严重:
```cpp
g_arm_control->setDeadzone(10.0f);  // 改大减少抖动
```

### 调整最大速度

如果运动太快:
```cpp
g_arm_control->setMaxRpm(50.0f);  // 默认 100,降低最大速度
```

## 调参技巧

### 1. 一次只调一个参数
不要同时改 Kp, Ki, Kd,否则不知道哪个起作用

### 2. 记录每次参数和效果
```
Kp=30, Ki=0, Kd=0 → 响应慢,有稳态误差
Kp=40, Ki=0, Kd=0 → 响应快,轻微震荡
Kp=35, Ki=0.5, Kd=0 → 响应快,无稳态误差,但超调
Kp=35, Ki=0.5, Kd=5 → 完美!
```

### 3. 从保守参数开始
宁可慢一点,也不要一开始就震荡失控

### 4. 角度轴和前后轴可以用不同参数
```cpp
// 角度轴需要更精确
g_arm_control->setAnglePID(40.0f, 1.0f, 8.0f);

// 前后轴可以快一点
g_arm_control->setForwardPID(50.0f, 0.5f, 5.0f);
```

## 观察和诊断

### 现象: 响应太慢
**原因**: Kp 太小
**解决**: 增大 Kp

### 现象: 震荡(来回摆动)
**原因**: Kp 太大,或缺少 D 项
**解决**: 减小 Kp,或加入 Kd

### 现象: 超调(冲过头再回来)
**原因**: Kp 太大,或 Ki 太大
**解决**: 减小 Kp 或 Ki,或加入 Kd

### 现象: 稳态误差(停在附近但不对准)
**原因**: 只有 P 项,或 Ki 太小
**解决**: 加入或增大 Ki

### 现象: 抖动(高频小幅震动)
**原因**: Kd 太大,对噪声敏感
**解决**: 减小 Kd,或增大死区

### 现象: 积分饱和(长时间偏离后突然冲过去)
**原因**: Ki 累积太多
**解决**: 减小 integral_limit,或减小 Ki

## 视觉误差格式说明

**当前假定格式**: `"A:<角度误差>,F:<前后误差>\n"`

**示例数据**:
```
A:10.5,F:-5.2
A:8.3,F:-3.1
A:2.1,F:0.5
A:0.3,F:0.1
```

**误差含义**:
- **正值**: 需要正向运动(角度顺时针,前后向前)
- **负值**: 需要反向运动(角度逆时针,前后向后)
- **绝对值**: 误差大小(像素?归一化值?取决于视觉算法)

**PID 如何使用**:
1. 收到误差 `angleError = 10.5`
2. 计算 P 项: `30.0 * 10.5 = 315 rpm`
3. 计算 I 项: `0.5 * (累积误差)`
4. 计算 D 项: `5.0 * (误差变化率)`
5. 输出: `P + I + D`,限幅到 ±100 rpm
6. 发送给电机

## 实际调参示例

### 场景1: 只用 P 控制(当前默认)

```cpp
void setup() {
    // ... 初始化 ...
    
    // 只用 P,不用 I 和 D
    g_arm_control->setAnglePID(30.0f, 0.0f, 0.0f);
    g_arm_control->setForwardPID(30.0f, 0.0f, 0.0f);
}
```

**效果**: 快速响应,但可能有稳态误差

---

### 场景2: 加入 I 项消除稳态误差

```cpp
void setup() {
    // ... 初始化 ...
    
    // P + I 控制
    g_arm_control->setAnglePID(30.0f, 0.5f, 0.0f);
    g_arm_control->setForwardPID(30.0f, 0.5f, 0.0f);
}
```

**效果**: 能完全对准目标,但可能超调

---

### 场景3: 完整 PID

```cpp
void setup() {
    // ... 初始化 ...
    
    // 完整 PID
    g_arm_control->setAnglePID(30.0f, 0.5f, 5.0f);
    g_arm_control->setForwardPID(30.0f, 0.5f, 5.0f);
    
    // 可选: 调整其他参数
    g_arm_control->setDeadzone(3.0f);        // 更小的死区
    g_arm_control->setMaxRpm(80.0f);         // 降低最大速度
    g_arm_control->setIntegralLimit(500.0f); // 防止积分饱和
}
```

**效果**: 快速、精确、稳定

## 总结

1. **从 P 开始**: 先找到合适的 Kp
2. **按需加 I**: 如果有稳态误差,加小的 Ki
3. **按需加 D**: 如果震荡,加小的 Kd
4. **逐步调整**: 一次改一个参数,观察效果
5. **记录结果**: 记下每组参数的表现

**推荐起点**:
```cpp
g_arm_control->setAnglePID(30.0f, 0.5f, 5.0f);
g_arm_control->setForwardPID(30.0f, 0.5f, 5.0f);
```

根据实际效果微调即可!
