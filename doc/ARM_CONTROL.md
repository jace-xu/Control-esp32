# 机械臂控制逻辑结构

本文件说明小车机械臂部分的控制逻辑与代码结构。底盘控制不在此范围内。

## 1. 整体分层

机械臂控制自上而下分为三层,职责清晰、互不越界:

```
  手柄输入 (A 键)
       │
       ▼
┌──────────────────┐
│  ArmSequence     │  任务编排层: 视觉伺服 + 上下电机自动序列状态机
│  (高层逻辑)       │  lib/ArmSequence/ArmSequence.h
└──────────────────┘
       │  调用
       ├───────────────┬───────────────┐
       ▼               ▼               │
┌──────────────┐ ┌──────────────┐      │
│  ArmControl  │ │ VisionSerial │      │  ArmControl: 三个电机的 PID/速度控制
│  (电机控制)   │ │ (视觉数据)    │      │  VisionSerial: 解析树莓派误差数据
└──────────────┘ └──────────────┘      │  lib/ArmControl, lib/VisionSerial
       │                               │
       ▼                               │
┌──────────────┐                       │
│  Motor       │                       │  单个电机的总线协议封装
│  (地址 5/6/7) │                       │  lib/Motor/Motor.h
└──────────────┘                       │
```

- `main.cpp` 只负责创建对象、读手柄、按帧把 A 键状态转发给 `ArmSequence`,不含任何机械臂业务逻辑。
- `ArmSequence` 是机械臂逻辑的唯一归属地,封装了全部状态机状态与时序常量。
- `ArmControl` 只管"怎么驱动电机"(PID 闭环 / 开环速度),不知道"什么时候该下降/夹取"。
- `VisionSerial` 只管"把串口字节解析成误差结构",不参与控制决策。

## 2. 三个机械臂电机

三个电机共用 Serial2 总线 (与底盘四个轮子同总线),通过地址区分:

| 地址 | 电机   | 控制方式            | 说明                         |
|------|--------|---------------------|------------------------------|
| 5    | 角度   | PID 闭环 (视觉伺服) | 根据角度误差旋转对准目标     |
| 6    | 上下   | 开环速度 (时间估算) | 下降/回升, 待位置反馈后改闭环 |
| 7    | 前后   | PID 闭环 (视觉伺服) | 根据前后误差进退对准目标     |

## 3. 视觉数据链路 (VisionSerial)

树莓派经 Serial1 (GPIO18=RX) 发来误差数据:

- 协议: `0xAA + ID(uint8) + 角度误差(int16 LE) + 前后误差(int16 LE)`,共 6 字节
- 误差有效范围 ±3000,超范围视为无效
- 数据超时阈值 500ms: 超过未收到新帧则 `valid` 置为 false

 `VisionSerial::read()` 每次调用会**排空整个 RX 缓冲, 只保留最新一帧**。
这避免了"每次只消费一包"导致的积压: 在 50Hz 消费 / 50Hz 生产下, 一次只取一包会让旧数据


## 4. ArmSequence: 任务编排核心

`ArmSequence` 是机械臂逻辑的核心。`main.cpp` 每帧 (约 50Hz) 调一次:

```cpp
g_arm_sequence->update(input.armServoTrigger);  // 参数 = A 键是否按住
```

### 4.1 按住 A 键时

每帧并行执行两件事:

1. **视觉伺服** (`runVisualServo`)
   - 从 `VisionSerial` 读最新误差
   - 数据有效 → `ArmControl::updateVisualServo()` 做角度轴 + 前后轴 PID 闭环;每 200ms 打印一次调试值
   - 数据无效 → `ArmControl::stopServo()` 停伺服并复位 PID 积分,防止数据恢复瞬间积分饱和窜动;首次失效打印一次警告

2. **上下电机自动序列** (`runVerticalSequence`) —— 见 4.2 状态机

### 4.2 上下电机状态机

```
   IDLE ──按下A──► DESCENDING ──6s到底──► GRIPPING ──等5s──► ASCENDING ──5s到顶──► IDLE
                       │                                          │
                    15s超时                                    12s超时
                       └──────────────► IDLE ◄────────────────────┘
```

| 状态        | 动作                          | 退出条件                        |
|-------------|-------------------------------|---------------------------------|
| IDLE        | 进入即开始下降, 复位 PID       | 立即转 DESCENDING               |
| DESCENDING  | 上下电机 -50rpm 下降           | 6s 到底转 GRIPPING / 15s 超时停 |
| GRIPPING    | 上下电机停, 底部等待夹取        | 5s 后转 ASCENDING               |
| ASCENDING   | 上下电机 +50rpm 回升           | 5s 到顶转 IDLE / 12s 超时停     |

时序常量 (下降 6s、夹取 5s、回升 5s、超时保护 15s/12s) 全部定义在 `ArmSequence` 类内。

> **注意**: 上下电机当前是**开环时间估算**, 没有位置反馈。`ArmControl::setVerticalPosition()`
> 已预留但未实现, 待电机总线支持位置控制协议后, 可把时间判断替换为位置判断。

### 4.3 松开 A 键时

`handleRelease()` 立即停止角度/前后伺服 (含复位 PID) 和上下电机, 状态机复位为 IDLE,
下次按 A 从头开始。

## 5. 安全机制 (main.cpp)

`loop()` 中, 以下任一情况都会调用 `safetyStopAll()` (同时停底盘和机械臂):

- 无手柄连接
- 手柄连接但数据超时 (蓝牙断流)
- 有连接但超过宽限期 (60ms) 无新数据帧

判断机械臂是否在运行用 `g_arm_sequence->isActive()` (A 键按住期间为 true)。
