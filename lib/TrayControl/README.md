# TrayControl — 物料盘控制

> 物料盘硬件子系统：有自己的步进电机（同步带）与两个舵机，负责入仓 / 压紧 / 出仓。
> 与底盘(1~4)、机械臂(5~7)共用 Serial2 总线，按地址直发命令（范式同 *BottomControl* / *ArmControl*）。
> 动作以**非阻塞状态机**实现，时机调度由上层 *TaskCoordinator* 负责。

## 现状
- 构造 `TrayControl()` 取 `ControlSerial::get_instance()` 单例 + 初始化两个舵机 PWM
- 禁用拷贝/赋值
- 动作以**非阻塞状态机**实现，每帧 `update()` 推进（不使用 `delay()` 死等）

## 接口规划（按下方流程实现）
- 硬件原语：`beltRunToAngle(deg)` / `readBeltAngle(deg)` / `beltStop()`、`liftUp()` / `liftDown()`、`baffleUp()` / `baffleDown()`
- 组合动作（启动即返回，靠状态机推进）：
    - `prepareStore()` — 放料前：舵机1 升起到承接位
    - `store()` — 放料后：舵机1 落下 + 同步带推进固定一小步；完成后计数 +1
    - `compact(targetDeg)` — 舵机2 降下 + 同步带走到压紧角（上层按数量查表传入），末态挡板**保持降下**
    - `dispense(nextDeg)` — 出仓：舵机1 升起→（机械臂夹走）→落下→同步带走到下一目标角；完成后计数 −1
    - `notifyPicked()` — 机械臂夹走完成通知，推进出仓后半段
- 推进/查询/急停：`update(now)` / `isBusy()` / `count()` / `stop()`

## 关键约定
- **不维护颜色队列**：颜色由机械臂侧自行读写 *ColorQueue*，与物料盘无关。TrayControl 只用一个整数计数器 `material_count` 记录**仓内物料数量**（查表的输入）。
- **查表归上层**：「数量 → 同步带绝对角度」的对照表属于 TaskCoordinator，不写进 TrayControl。原语只接收"走到多少度"。
- **不能用 `delay()` 死等**：等舵机/电机到位一律靠每帧 `update()` 轮询，避免阻塞 50Hz 主循环与急停。

## 一、机构组成

物料盘是一条**环形同步带**（立体、可整圈循环转动），同步带上贴有**一个挡片**。物料块松散地排成一列堆在挡片前方，挡片随同步带转动，推着这一列物料沿带子绕圈走。整体设计为一头进、一头出，进出共用**同一个出入口**。

- **同步带步进电机（8 号）**：驱动同步带转动，挂在 Serial2 电机总线，地址 **8**。采用**绝对角度位置控制**，约定**顺时针为负、逆时针为正**，整体一直往一个方向推进。
- **舵机1（顶料舵机）**：位于出入口**正下方**，PWM 驱动，两个固定位——**升起 / 落下**，**初始位 = 落下**。升起时把停在口上的物料往上托高，使其顶部高于仓沿，方便机械臂夹取；入仓放料前也先升起做"承接"。
- **舵机2（挡板舵机）**：位于出入口**仓内一侧**，PWM 驱动，两个固定位——**升起 / 降下**，**初始位 = 升起**。降下时挡住物料做定位（压紧 / 出仓时使用），让目标物料完全暴露在出入口、正对舵机1上方。

> 硬件占用提醒：夹爪已占用 LEDC 通道 4、GPIO13。两个舵机需改用 LEDC 通道 5、6，引脚另选。电机地址 8 已避开底盘(1~4)、机械臂(5~7)。

## 二、入仓流程

舵机2 保持升起不动，舵机1 配合。每入一块大致重复（分两次调用，中间隔机械臂放料）：

1. **放料前**（`prepareStore()`）：舵机1 **升起**到承接位。
2. 机械臂将物料放到出入口。
3. **放料后**（`store()`）：舵机1 **落下**，随后同步带带挡片把刚放入的物料**沿带子往里推进固定一小段**（推进量为**固定值**，不查表），让出口位给下一块；完成后**物料计数 +1**。
4. 循环往复，物料在带上保持**松散排列**，逐块进仓。

> 入仓阶段物料保持松散即可，不在每次入仓时压紧。压紧统一在出仓前按"查表"一次性完成（见下）。

## 三、压紧（出仓前必做）

由于带上物料松散排列，不同数量时整列占位长度不同。**出仓前必先压紧**：

1. 舵机2（挡板）**降下**定位，并**保持降下**（不再升回，后续出仓继续用它当挡板）。
2. 同步带按**当前物料数量查表**得到的**绝对角度**移动，把整列物料推压贴紧——压紧到位时，队首物料**已经被送到出料口**。

> 关键约定：**"数量 → 绝对角度"的对照表属于上层（TaskCoordinator），不写进 TrayControl 原语。** 原语只接收"走到多少度"。

## 四、出仓流程

前提：已先压紧，故舵机2 已是降下状态，**出仓全程不动舵机2**，物料也已在出料口。

1. 舵机1（顶料）**升起**，将出料口的物料托高。
2. 机械臂夹走物料（夹走完成由上层 `notifyPicked()` 通知物料盘）。
3. 舵机1 **落下**。
4. 同步带移动到**"物料数 −1"**对应的查表角度，把下一块物料送到出料口就位；完成后**物料计数 −1**。

## 五、物料记录

**物料盘不维护颜色队列。** 颜色的记录与读取由机械臂侧自行操作 *ColorQueue*（`lib/ColorQueue`），与物料盘无关。TrayControl 只维护一个**整数计数器 `material_count`**，表示仓内当前物料数量——它是压紧 / 出仓时**查表的输入**：入仓完成 +1、出仓完成 −1。对外提供 `count()` 供上层查表使用。

## 六、待测/待定参数

- 各舵机的"升起/落下"具体角度
- 两个舵机的 GPIO 引脚
- 同步带移动转速、入仓固定推进增量（度）、到位判定阈值
- 各舵机动作是否需要固定 settle 等待时间（台架调试时确定）
- "物料数量 → 压紧绝对角度"对照表、"物料数 −1 → 出料定位绝对角度"对照表（均在上层）
- 出料口位置需与机械臂 *PlaceSequence* 的固定取料姿态对齐校准
