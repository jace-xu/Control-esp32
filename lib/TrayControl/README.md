# TrayControl — 物料盘控制（骨架）

> 物料盘硬件子系统：有自己的电机/舵机，负责存料 / 转位 / 出料。
> 与底盘(1~4)、机械臂(5~7)共用 Serial2 总线，按地址直发命令（范式同 *BottomControl* / *ArmControl*）。
> **[ ! ] 当前为占位空类**，动作方法与电机地址等硬件细节确定后再补。

## 现状
- 构造 `TrayControl()` 取 `ControlSerial::get_instance()` 单例
- 禁用拷贝/赋值
- **无任何动作方法**（待硬件细节）

## 待补（硬件确定后）
- 动作接口，例如：
    - `store(color)` — 接收机械臂放入的物料，存入槽位
    - `dispense(color)` — 把指定颜色物料送到取料位供机械臂夹取
    - `update(t)` — 物料盘自身状态机/到位推进（若动作非阻塞）
    - `isBusy()` — 是否正在执行动作
    - `stop()` — 急停所有物料盘电机

## 待定问题
- 槽位数量、转位方式（步进角度？到位反馈？）
- 出料动作（推杆？转到取料口？）
- 存料记录什么（槽位↔颜色映射？）
