# ColorQueue — 物料颜色待抓队列

> 定长 FIFO 环形缓冲，存放待抓物料的颜色（1=绿/2=蓝/3=红）。
> 纯数据结构，与机械臂状态机解耦；供 *ArmSequence* 及未来上层协调器/物料盘复用。
> [ ! ] 非线程安全（仅主循环单线程使用）；容量固定 `kCapacity`(16)。

## 接口
- `enqueue(color)` — 入队（队尾）；返回 false=队满丢弃
- `dequeue(color)` — 出队（队首）；返回 false=队空，out 不变
- `dropLast()` — 撤销最近一次入队（回退队尾）；返回 false=队空
    - 供阶段1 中止回滚：本轮至多入队一个且未出队，故队尾必为本轮所记颜色
- `clear()` — 清空
- `count()` / `isEmpty()` / `isFull()` — 状态查询

## 说明
- 不打印日志：是否"队满丢弃"、入队/出队数量由调用方按需打印（队列只负责存取）
- 阶段1（记录）每轮 `enqueue` 一个颜色；阶段2（消费）按 FIFO `dequeue` 逐个取
