## 这是电机控制串口的工具类，集成了信息发送、读取和线程锁的功能
- 该类只有一个全局单例
    - 使用指针或引用接收 *ControlSerial::get_instance()* 返回的对全局单例的引用
    - 使用 *initialize(波特率, RX引脚, TX引脚)* 以初始化串口
    - 使用 *release()* 以释放串口

- 命令的生成和发送是分开的
    - 普通单条命令：
        - 调用 *generate_某个操作_command(参数)* 生成命令，此时命令会被存放至短缓冲区
        - 调用 *send_command()* 将短缓冲区的命令发送
    - 多机长命令：
        - 先调用 *threading_lock()* 为线程上锁（单线程无需考虑）
        - 调用 *generate_某个操作_command(参数)* 生成命令，此时命令会被存放至短缓冲区
        - 调用 *append_command()* 将短缓冲区的命令加入到长命令缓冲区中
        - 重复生成命令、加入长缓冲区的操作
        - 调用 *send_long_command()* 将长缓冲区的命令发送
        - 调用 *threading_unlock()* 将线程解锁（单线程无需考虑）
    - 调用 *clear_command()* 或 *clear_long_command()* 可以清空短、长缓冲区的内容

- 线程锁
    - 上锁后，如果别的线程同时调用了串口对象，则别的线程会进入等待，直到本线程解锁后才会释放使用权
    - 线程锁的 *threading_lock()* 和 *threading_unlock()* **必须配对使用**
        - [ ! ] 如果只上锁未解锁，别的线程调用了该对象后将会永久阻塞
        - [ ! ] 如果没上锁直接解锁了，程序可能会直接崩溃，或产生意义不明的BUG

- 信息读取
    - 功能尚未添加

- 注意事项
    - [ ! ] 如果没有初始化，则无法使用串口对象（线程可使用串口对象时直接返回）
    - 无论是否多线程，只执行一步操作的话不需要上锁（函数内自带线程锁）
    - 长缓冲最多可容纳7条最长的电机消息(七个电机都是位置模式时)
    - 使用长命令时，不建议同个电机执行多个操作
    - 解锁线程后别的线程就可以修改缓冲区了，如果你在解锁前没有发送，命令可能会丢失
    - 更换电机地址的操作有风险，不建议使用
