== Version 1.0.1 ==

其他未用到的设置(CAN波特率、通讯返回类型、相电流、电压限制等等，保持默认即可，后续有需要再更改说明)
有的电机是旧的，部分设置没有或者名称不一样，忽略或按照下面的选项修改即可

[ Hide ]-(隐藏开机LOGO):
    == Enable ==

[ Lock ]-(锁定菜单，防误触):
    == Enable ==

[ Cal ]-(校准电机，点击开始，有选项的话选):
    == Cal_MFL ==

[ MotType ]-(步距角，不要改):
    == 1.8° ==

[ FWType ]-(固件类型，不要改):
    == FW_Emm ==

[ EmmTurbo ]-(狂暴模式，不要改):
    == Disable ==

[ CtrlMode ]-(控制模式，不要改):
    == CR_VFOC ==

[ P_Pul ]-(脉冲模式):
    == PUL_OFF == (如果不需要脉冲控制)
    == PUL_ENA == (如果需要脉冲控制)

[ P_Serial ]-(通讯端口模式，不要改):
    == UART_FUN ==

[ En ]-(使能模式，不要改):
    == Hold ==

[ Dir ]-(脉冲模式的方向引脚电平模式):
    == CW或CCW == (根据你的需求设置，仅限脉冲模式)

[ MStep ]-(脉冲模式下的细分步数，即原本一步的角度需要走多步，尽量别动):
    == 16 ==

[ MPlyer ]-(脉冲模式下细分插补，不要改):
    == Enable ==

[ AutoSSD ]-(自动息屏，建议关闭):
    == Disable ==

[ UartBaud ]-(通讯波特率，除了CAN):
    == 115200 ==

[ ID_Addr ]-(电机的地址，不能超过16，广播地址是0):
    == 你的电机地址 ==

[ Checksum ]-(通讯校验码，不要改):
    == 0x6B ==

[ Response ]-(电机收到消息后的返回模式，不要开启)
    == None ==

[ S_Vel_IS ]-(速度模式是否缩小十倍输入，要开启):
    == Enable ==

[ S_PosTDP ]-(位置模式是否放大100倍发送，有的电机不支持，所以统一关闭):
    == Disable ==

[ Clog_Pro ]-(堵转保护模式):
    == AutoZero ==

[ Restore ]-(恢复出厂设置，在电机出现问题时使用)

[ Exit ]-(退出菜单)
